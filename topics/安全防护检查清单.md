## 一、按阶段的家居安全清单

> 🔁 使用方式：进入每个新能力阶段（会翻身/会爬/会走/会攀爬）当天，全家做一次对应层级的排查（对应锚点 [M4-22](../stages/04-婴儿期-4至6月龄.md)、[M7-20](../stages/05-婴儿期-7至9月龄.md)、[M10-17](../stages/06-婴儿期-10至12月龄.md)、[Y18-21](../stages/08-幼儿期-1岁半至2岁.md)），此后每月快检。

### 层级 0：出生前（备产期就位）
- [ ] 婴儿床：硬床垫、缝隙 <2 指、无床围软垫、空床原则（[P-24](../stages/01-怀孕阶段.md)）
- [ ] 安全座椅（反向提篮）装后排、晃动 <2.5cm（[P-25](../stages/01-怀孕阶段.md)）
- [ ] 室温 20～26℃、加湿到 40%～60%；窗帘绳收纳高位

### 层级 1：会翻身前（0～4 月）
- [ ] 任何平面（床/沙发/尿布台）**绝不独留**——"就拿个东西"也不行
- [ ] 睡眠五铁律（仰卧/空床/睡袋/同房不同床/不过热）——见 [睡眠指南](睡眠管理指南.md)
- [ ] 洗澡水温计 37～38℃；**洗澡全程手不离娃**
- [ ] **绝不摇晃**；家中所有看护人知晓

### 层级 2：会爬期（7～10 月）——全屋深度排查
- [ ] 蹲下来以宝宝视角**爬一遍全屋**
- [ ] 低位插座全部装防护盖/换安全插座；电线固定收起
- [ ] **所有立柜/书架/电视柜固定上墙**（防倾倒）
- [ ] 桌角防撞条；抽屉柜装锁（尤其下层）
- [ ] 房门防夹指卡；卫生间/厨房/阳台随手关门
- [ ] 地面每天捡拾——**<4cm 小物全部清场**（硬币/瓶盖/药片/耳塞/珠子）
- [ ] 药品/维生素/清洁剂/洗衣凝珠/化妆品：**上锁**或最高层带门柜（**不是放高就行**——孩子会搬凳）
- [ ] **纽扣电池**（遥控器/玩具/体温计）——电池仓螺丝拧紧＋备件上锁（误吞=2 小时灼穿食道，最凶险）
- [ ] **磁力珠**不入家（误吞多颗肠道穿孔）
- [ ] 垃圾桶加盖隐蔽；有毒植物（滴水观音/绿萝汁液）移出
- [ ] 楼梯上下口装门栏；**学步车零容忍**（[M7-22](../stages/05-婴儿期-7至9月龄.md)）
- [ ] 窗户开窗限位 <10cm；**纱窗不防坠**

### 层级 3：学步期（10～18 月）
- [ ] **撤桌布**（热汤倾覆=头面烫伤首因）；热饮热锅**绝对内移**、锅柄朝内、用后排灶眼
- [ ] 能够到的新台面清空（热水杯、刀具、药）
- [ ] 马桶盖加锁；热水器出水调 ≤49℃
- [ ] 窗边/阳台**清空一切可蹬踏物**（椅/箱/花架）；阳台门加锁
- [ ] 高脚餐椅五点带每次扣好；电器门锁（烤箱/洗碗机/洗衣机）
- [ ] 食物窒息清单上墙（见下节）；**坐着吃饭**铁律

### 层级 4：攀爬/奔跑期（18 月～6 岁）
- [ ] 攀爬能力复核：窗、阳台、书架顶——固定与清空再查一轮
- [ ] 厨房"禁区"或"安全区"划定；教"热的/烫的"边界词
- [ ] 家庭工具/锐器收纳上锁；自行车/滑板车**头盔+护具**为穿车即戴
- [ ] 电器安全教育（湿手不碰插座/不拉拽电线）
- [ ] 12 岁前**不骑车上马路**；小区骑车也有"停车线"规则
- [ ] 独处规则：6 岁前**不独处**（包括车内——**任何时候不把孩子单独留车内**）

## 二、交通安全

**安全座椅全程规范（出生即用，违法的不仅是危险）**
- **0～15 月（或按座椅上限）**：**反向安装**（后向），后排；
- **15 月～4 岁**：反向坐到体重身高上限，再转正向（五点式安全带），**尽量延后转正向**（后向保护颈椎，多坐一个月是一天）；
- **4 岁～身高 145cm/12 岁**：增高垫（booster）+成人三点式安全带（带子跨肩胛与髋部，不勒颈部腹部）；
- **12 岁以下一律坐后排**；副驾驶不坐（气囊伤害）；
- 每次检查：安全带**紧到只能塞进两指**、卡扣清脆入位、座椅晃动 <2.5cm、冬季**脱掉羽绒服再系带**（蓬松=虚扣）。
- **电动自行车/自行车**：**不在车流中带娃**；合法载人按当地规定（多数城市电动自行车仅可载 1 名 12 岁以下、须戴头盔——**大人小孩都戴**）。
- 行走：牵手（腕带可选）、路口"停-看-走"、倒车盲区教育（不在车后玩；下车看后视镜再开门）。

## 三、十大伤害场景与对策

| # | 场景 | 对策 |
|---|---|---|
| 1 | **窒息（睡眠）** | 空床+仰卧+睡袋（0～1 岁铁律，见 [睡眠指南](睡眠管理指南.md)） |
| 2 | **异物窒息（食物）** | **4 岁前禁**：整粒坚果、整颗葡萄/圣女果（切四瓣）、果冻、硬糖软糖、爆米花、大勺花生酱、Q 弹丸子（切碎）；坐着吃、跑跳笑闹不吃、大人同在 |
| 3 | **异物窒息（小物）** | 卫生纸筒测试（能穿过=危险）；纽扣电池/磁力珠专项清剿 |
| 4 | **坠落（床/窗/楼梯）** | 床护栏/床垫落地；窗限位器+清空蹬踏物；楼梯门栏；尿布台一手不离 |
| 5 | **溺水** | **一寸水规则**：洗澡不离人、水桶浴缸即空、马桶盖锁、卫生间关门；游泳课≠免死牌 |
| 6 | **烫伤** | 撤桌布、热源内移、热水器 ≤49℃、水杯"热饮位"制度；处理：**冲-脱-泡-盖-送**（见下） |
| 7 | **中毒** | 药/清洁剂/凝珠上锁；**不把药说成"糖"**；来访客包收纳 |
| 8 | **道路交通** | 安全座椅全程+牵手+头盔+不在车后玩+不单独留车内 |
| 9 | **走失** | 盯人交接制（"你现在看着他"）；教育：原地等+找制服；**走失立即报警**（不等 24h）；防走失包/环（人多场合） |
| 10 | **非故意伤害（人）** | 身体安全教育（[K4-19](../stages/11-学龄前-4至5岁-幼儿园中班.md)）；接送暗号（[K5-18](../stages/12-学龄前-5至6岁-幼儿园大班.md)） |

## 四、急救要点（速查卡）

> 📌 **强烈建议：全家（含常帮忙的长辈/阿姨）参加一次线下儿童急救培训（红十字会/医院公益课，约半天）。** 以下为速查，不能替代培训。

### 气道异物梗阻（噎住）
- **能咳嗽能出声**＝部分梗阻：**鼓励用力咳**，不拍背不抠喉（可能把松动卡死）。
- **不能出声/面色涨红青紫/无声挣扎**＝完全梗阻：**立即施救＋呼救 120**
  - **<1 岁（婴儿）**：5 次**拍背**（面朝下头低位，掌根拍两肩胛之间）＋5 次**胸部冲击**（面朝上，两指按压两乳连线下一指）循环；
  - **1～8 岁**：**海姆立克**——站/跪于背后，双手环抱剑突下（肚脐上两横指），快速向内向上冲击 5 次，循环至异物排出或宝宝失去意识（失去意识→心肺复苏）。

### 烫伤
**冲（流动冷水 15～20 分钟）→脱（小心去除衣物，粘连不撕）→泡（冷水持续）→盖（清洁纱布/干净布）→送（医院）**。
❌ 不涂牙膏/酱油/紫药水/香油/冰块直敷。

### 头部撞击
- 48 小时观察窗：**呕吐（尤其反复）→嗜睡叫不醒→尖叫哭闹不止→走路异常/一侧肢体无力→耳鼻流血流清液→瞳孔不等大 → 立即急诊 CT**。
- 头上起包：冷敷 15 分钟（毛巾裹冰袋）；"哭着哭着自己睡着了"（撞后疲劳嗜睡但可唤醒）需留观；**从 >1 米/楼梯跌落或直接撞硬物尖角 → 保险起见就医**。

### 误吞（先记住"吞了什么+多久了"）
- **纽扣电池/磁力珠/尖锐物/整瓶药物 → 2 小时内急诊**（不可催吐）；
- 误服药物/化学品：**带包装立即急诊**，遵毒物中心指引（不催吐不喝水稀释，先问医生）；
- 硬币等光滑小物单枚：多数 2～3 天随大便排出（每日筛便确认），出现腹痛呕吐发热→就诊。

### 惊厥（抽搐）
- **侧卧位**（防误吸）、解开衣领、清空周围硬物、**计时**；
- ❌ 不塞任何东西进嘴、不掐人中、不捆抱压制；
- **>5 分钟或首次发作或抽后精神差 → 120**；热性惊厥多数 3～5 分钟自行停止（见 [常见疾病](常见疾病与应对.md)）。

### 心肺复苏（CPR）概念（以培训实操为准）
- 无反应无呼吸 → 呼救（指定某人打 120 拿 AED）→ 胸外按压：婴儿双指/双手环抱双拇指，儿童单手或双手掌根，**胸骨下半段、深度胸廓 1/3（婴儿 4cm/儿童 5cm 级）、频率 100～120 次/分**，30 按压:2 人工呼吸循环（不愿口对口可纯按压），直到恢复/接管。

## 五、儿童安全教育要点

> 分龄递进——**0～3 岁安全靠大人改环境；3 岁起安全开始"装进孩子脑子里"**（每季度强化，场景化演练优于说教）。

- **2 岁半～3 岁**：单词级边界——"烫！""停！"（动作+表情+一致反应）；牵手机制；身体隐私启蒙（尿布区规则："除了爸妈医生护理，别人不碰"）。
- **3～4 岁**：红灯停绿灯行；"走失三步"（原地站+喊爸妈+找制服人员）；背父母姓名电话；身体安全教育五要点（[K4-19](../stages/11-学龄前-4至5岁-幼儿园中班.md)：身体主权/泳衣规则/警报情境/应对三步/不保密规则）。
- **4～5 岁**：过马路实战（看左-看右-再看左）；"不接受陌生人糖果/礼物/搭车"；家庭地址门牌号背熟；火灾"低姿捂口鼻+不藏+找出口"游戏化演练。
- **5～6 岁**：上下学固定路线+安全屋；接送暗号；110/119/120 会拨会说；独自在家四不（不给任何人开门/不说独自在家/不碰灶具/不爬窗）；** swimming 泳技能**推进。
- **贯穿原则**：安全教育**不吓唬**（恐惧教育让孩子遇事僵住）；演练>讲解；**大人的监护一致性**是所有教育的底座——**"交接盯人"**（明确"现在谁看着孩子"）杜绝监护真空。
