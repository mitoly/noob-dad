# 🍼 新手父母育儿检查手册（怀孕 → 0 岁 → 小学入学前）

> **这是什么**：一套给新手父母的"全阶段育儿检查清单"——从备孕那天起，到孩子背起书包走进小学大门为止，**每个时间节点该检查什么、怎么评估、什么时候开始、什么时候停止**，逐项列全。
>
> **设计哲学**：不适用的检查项你自然跳过；但**没列出来的项，你就无从知道它存在**——所以本手册刻意做到"事无巨细，宁多勿漏"。
>
> **⚠️ 免责声明**：本手册基于中国国家标准与权威指南整理（国家免疫规划 2021 版、国家基本公共卫生服务规范、中国居民膳食指南 2022、WHO 儿童生长标准、0～6 岁儿童发育预警征象、眼/口腔保健规范等），**为育儿参考工具，不能替代医生面诊**；各地程序细节以当地社区与接种门诊通知为准，与医生意见冲突时以医生为准。

## 📖 检查项统一格式

每个检查项长这样：

```
### ▢ M4-05 【生长】每双周测量体重、身长、头围
- ⏱ 时间窗口：开始 ～ 截止（含明确的起止）
- 🔁 检查频率：每天 / 每周 / 每双周 / 每月 / 每季 / 每半年 / 一次
- 🎯 适用条件：（仅条件性条目才有，不满足可跳过）
- 📋 评估方法：具体怎么做、怎么量、怎么算
- ✅ 通过标准：达到什么状态算正常/合格
- ⚠️ 预警信号：出现什么情况需要就医或加强干预
- 📝 说明：背景知识、原理、常见误区
- 🔗 关联：跳转到相关专题或前后阶段
```

| 符号 | 含义 |
|---|---|
| ▢ | 检查项复选框（可打印后手工打勾，或在编辑器中把 `▢` 改成 `☑`） |
| ⏱ | 时间窗口（**每项必有开始与截止**；「截止」表示该项停止检查的时点） |
| 🔁 | 频率（随年龄自动拉长：按天 → 按周 → 按双周 → 按月 → 按季 → 按半年 → 按年） |
| 🎯 | 适用条件（条件不满足时**自动跳过**，无需评估） |
| 📋 | 评估方法（父母可操作的具体动作） |
| ✅ | 通过标准（本次评估"过关"的判据） |
| ⚠️ | 预警信号（红线：出现即建议就医，不拖延） |
| 📝 | 说明（为什么、原理、误区） |
| 🔗 | 关联跳转 |

**类别标签**（出现在每项标题的【】中）：
【产检】【物品准备】【证件】【疫苗】【喂养】【生长】【发育】【体检】【护理】【睡眠】【安全】【疾病】【早教】【自理】【心理】

## ⚙️ 核心规则

### 1. 时间窗口的"开始"与"截止"

- 每个检查项都写明**什么时候开始做、什么时候停止做**。
- 例：新生儿黄疸需**每天**监测，开始=出生第 2 天，截止=生后 2 周（黄疸消退后）；又如「每双周测量生长」开始=满 4 月龄，截止=满 6 月龄，之后该项**停止**，由「每月测量」取代。
- 错过窗口的项（尤其是疫苗、筛查）会标注「错过怎么办」。

### 2. 频率随年龄递变

| 年龄段 | 生长监测频率 | 发育评估频率 | 日常观察 |
|---|---|---|---|
| 0～28 天（新生儿期） | 体重：每天～隔天 | 出院前全面评估 | 黄疸/脐部/大小便：每天 |
| 1～3 月龄 | 体重：每周；身长头围：每月 | 每月对照里程碑 | 每天常规护理 |
| 4～6 月龄 | 体重身长头围：**每双周**（本阶段特有，满 6 月后停止） | 每月对照里程碑 | 每天常规护理 |
| 7～12 月龄 | 每月 | 每月对照里程碑 | 每周汇总 |
| 1～2 岁 | 每季度 | 每 2～3 个月 | 每周汇总 |
| 2～3 岁 | 每半年 | 每 3 个月 | 每月汇总 |
| 3～6 岁 | 每半年 | 每半年 | 每月汇总 |

### 3. 跳过规则

- 任何条目若**不适用于你家宝宝**（例如：纯母乳充足故不需要计算奶粉量、已接种五联疫苗故跳过对应的免费单苗条目、宝宝已提前掌握某项技能），直接跳过即可，**但建议至少读一遍「说明」**——很多误判（把正常当异常、把异常当正常）源于信息缺失而非评估本身。
- 标注 🎯 的条目是**条件性条目**；未标注的是**普遍适用条目**。

### 4. 月龄计算

- **满 X 月龄** = 出生日期加 X 个自然月的那一天（如 3 月 15 日出生 → 满 6 月龄 = 9 月 15 日）。
- 疫苗接种的常规窗口为「满 X 月龄 ～ 满 X+1 月龄」，尽量不推迟；因故推迟的，见 [疫苗接种总表](topics/疫苗接种总表.md) 的补种原则。
- **早产儿**（孕 37 周前出生）：**2 岁前**的发育里程碑评估一律使用**纠正月龄**（实际月龄 − 提前的周数）；疫苗接种使用**实际月龄**（不受早产影响，按出生日期正常接种；体重≥2500g 即可接种乙肝疫苗等）。

### 5. 建议的使用节奏

- **每天**：新生儿期各项日常观察（约 5～10 分钟）。
- **每周日晚上**：「家庭检查会」——过一遍本阶段文件中的周频/双周频条目（约 15 分钟）。
- **每月龄节点**（宝宝"满 X 月"当天附近）：完成该月龄的疫苗、体检、发育对照。
- **每进入新阶段**：通读下一个阶段文件的总表，提前准备物品与知识。
- 建议配合一个记录本或本手册的电子副本，记录每次测量的数值与打勾状态，体检时带给医生看。

## 🔁 检查频率递变总表

| 频率 | 适用检查项 | 阶段 |
|---|---|---|
| **按天** | 黄疸、脐部、大小便、体温、睡眠安全 | 0～28 天 |
| **按周** | 体重测量、奶量重算 | 新生儿期～3 月龄 |

| **每季度** | 生长监测、体态观察 | 1～2 岁 |
| **每半年** | 生长监测、视力+屈光、涂氟、发育对照 | 2～6 岁 |
| **每年** | 全面体检、流感疫苗、兴趣班复盘 | 3 岁～入学 |
